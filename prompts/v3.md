# v3 — the full specification

```text
Read the files in course_material/: the Lecture 2 slides on the workshop
problem (PDF) and the MATLAB code that solves it.

Make ONE web page, index.html, that teaches a first-year engineering student
why the optimum of a linear programme sits at a corner of the feasible region,
using this workshop example.

The page:
1. A plot of the (x1, x2) plane: the three machine constraints as coloured,
   labelled lines, and the feasible region shaded.
2. A slider for the profit target k that moves the profit line
   50 x1 + 100 x2 = k across the plot. Show whether the line still touches
   the region, and mark the last corner it touches.
3. A table of the corners of the region and their profit; highlight the best.
4. Hovering over (or tapping) any point of the plot shows x1, x2, the profit,
   and whether that plan is feasible.
5. Three short "Try this" instructions, in plain words.

Rules:
- Use exactly the numbers in the course material. Compute the corners and the
  optimum in the page's own JavaScript; do not type the answers in.
- One self-contained file: HTML, CSS and JavaScript inside, no libraries,
  no internet. It must also fit a phone screen.
- First tell me your plan in five lines, then write the file.
```

The result: [claude/v3/](../claude/v3/): one idea, built as specified, but the star gives the answer away and the LP box is cut off on a phone.
